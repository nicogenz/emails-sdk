```ts
import { createClient } from '@nicogenz/emails-sdk';
import { resend } from '@nicogenz/emails-sdk/resend';

const email = createClient({
  provider: resend({ apiKey: process.env.RESEND_API_KEY! }),
});
```

## Options

| Option   | Type           | Required | Description                     |
| -------- | -------------- | -------- | ------------------------------- |
| `apiKey` | `string`       | Yes      | Your Resend API key.            |
| `fetch`  | `typeof fetch` | No       | A custom `fetch` implementation. |

## Notes

- `tags` are sent as Resend tags. Resend only allows ASCII letters, numbers, underscores and dashes in tag names and values.
- `idempotencyKey` is supported.
- `sendBatch` uses Resend's batch endpoint and splits batches larger than 100 emails. Batches with attachments or idempotency keys are sent one by one, because Resend's batch endpoint doesn't support them.
