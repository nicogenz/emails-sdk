```ts
import { createClient } from '@nicogenz/emails-sdk';
import { postmark } from '@nicogenz/emails-sdk/postmark';

const email = createClient({
  provider: postmark({ serverToken: process.env.POSTMARK_SERVER_TOKEN! }),
});
```

## Options

| Option          | Type           | Required | Description                                            |
| --------------- | -------------- | -------- | ------------------------------------------------------ |
| `serverToken`   | `string`       | Yes      | Your Postmark server API token.                        |
| `messageStream` | `string`       | No       | The message stream to send through. Postmark uses `outbound` if not set. |
| `fetch`         | `typeof fetch` | No       | A custom `fetch` implementation.                       |

## Notes

- `tags` are sent as Postmark `Metadata`.
- `idempotencyKey` isn't supported. Passing one throws an `EmailError` with the code `unsupported`.
- `sendBatch` uses Postmark's batch endpoint and splits batches larger than 500 emails.
