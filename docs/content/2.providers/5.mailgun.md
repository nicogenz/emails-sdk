```ts
import { createClient } from '@nicogenz/emails-sdk';
import { mailgun } from '@nicogenz/emails-sdk/mailgun';

const email = createClient({
  provider: mailgun({
    apiKey: process.env.MAILGUN_API_KEY!,
    domain: 'mg.acme.com',
  }),
});
```

## Options

| Option   | Type           | Required | Description                                                  |
| -------- | -------------- | -------- | ------------------------------------------------------------ |
| `apiKey` | `string`       | Yes      | Your Mailgun API key.                                        |
| `domain` | `string`       | Yes      | The sending domain configured in Mailgun.                    |
| `region` | `'us' \| 'eu'` | No       | Use `eu` for domains in Mailgun's EU region. Defaults to `us`. |
| `fetch`  | `typeof fetch` | No       | A custom `fetch` implementation.                             |

## Notes

- `tags` are sent as Mailgun custom variables (`v:` fields).
- `idempotencyKey` isn't supported. Passing one throws an `EmailError` with the code `unsupported`.
- `sendBatch` sends the emails one by one, because Mailgun has no endpoint for sending different emails in one request.
- Mailgun identifies inline images by their filename, so an attachment with a `contentId` is uploaded under that ID as its filename.
- The returned `id` is Mailgun's message ID without the surrounding `<` and `>`, as it appears in webhook events.
