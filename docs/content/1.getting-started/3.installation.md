::code-group

```bash [npm]
npm install @nicogenz/emails-sdk
```

```bash [pnpm]
pnpm add @nicogenz/emails-sdk
```

```bash [yarn]
yarn add @nicogenz/emails-sdk
```

```bash [bun]
bun add @nicogenz/emails-sdk
```

::

The package has no dependencies. Every provider ships inside it, so there's nothing else to install.

## Requirements

- Node.js 22 or later, or another runtime with the standard `fetch` API.
- ESM. The package doesn't ship a CommonJS build.
